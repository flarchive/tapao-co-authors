# Co-Authors

![License](https://img.shields.io/badge/license-MIT-blue.svg) [![Latest Stable Version](https://img.shields.io/packagist/v/tapao/co-authors.svg)](https://packagist.org/packages/tapao/co-authors) [![Total Downloads](https://img.shields.io/packagist/dt/tapao/co-authors.svg)](https://packagist.org/packages/tapao/co-authors)

A [Flarum](https://flarum.org) extension. A Flarum extension that adds co-writing to discussions

## Installation

Install with composer:

```sh
composer require tapao/co-authors:"*"
```

## Updating

```sh
composer update tapao/co-authors:"*"
php flarum migrate
php flarum cache:clear
```
